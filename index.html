Overhead Panel

The overhead panel contains controls for aircraft systems, including electrical, fuel, hydraulics, pneumatics, and lighting. It follows Airbus's "dark cockpit" philosophy, meaning lights only turn on if something requires attention.

Glareshield

Located directly below the windshield, the glareshield houses the Flight Control Unit (FCU) and EFIS control panels. This is where pilots manage short-term autopilot instructions like speed, heading, and altitude adjustments.

Main Panel

The main panel directly faces the pilots and contains the Primary Flight Displays (PFD) and Navigation Displays (ND). It provides critical, real-time information regarding the plane's speed, attitude, altitude, and flight path.

Pedestal

Positioned between the two pilot seats, the center pedestal holds the thrust levers, engine start panels, flap and slat controls, speed brake lever, and the Multi-function Control Display Units (MCDU) used for entering flight plans.
